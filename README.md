# Volt Pro

موقع Volt Pro على GitHub Pages: https://tonysyds28-dot.github.io/volt-pro-website/

## فين كل حاجة

- **الصفحة الرئيسية:** `index.html`، والتنسيق في `css/style.css`، والسكريبتات `js/yaml-loader.js` و `script.js`.
- **المشاريع:** `data/wip/index.json` (تحت التنفيذ) و `data/done/index.json` (المنفذة، الأحدث فوق والأقدم تحت).
- **الاسم والرقم ورسالة الواتساب والحسابات:** `data/settings.json`.
- **الصور:** صور المشاريع في `image/`، ولكل صورة نسخة صغيرة للمعرض في `image/thumbs/` بنفس المسار (عرض 640). الصورة الكبيرة بتتفتح لما الزائر يدوس. لو النسخة الصغيرة مش موجودة، الموقع بيعرض الكبيرة.
- **تطبيق البيت الذكي:** صفحته وصفحتا الخصوصية والشروط في `smart-home/`.
